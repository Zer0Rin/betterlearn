# 玻璃质感设置

设置 → 外观 → 玻璃质感：0 为通透液态，100 为磨砂玻璃，默认 35。拖动实时更新预览、标题栏、侧栏与收起入口；使用浏览器本地存储自动记忆。外观不依赖模型配置接口，也不需要点击“保存设置”。写入失败会提示，但当次外观仍生效。

延续黑白灰、#1769FF 与深蓝的方向。蓝色预览图形帮助观察折射与模糊的区别；桌面加入淡蓝形状，让侧栏下方存在可见背景。正文和控件处于独立前景层，不进行模糊或透明处理。

## 实现

- 参考 [rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react) 的背景折射思路，未新增 npm 依赖。使用自有圆角边缘位移场、SVG feDisplacementMap 和 CSS backdrop-filter。
- 滑杆连续调节模糊 0.4–24px、白色填充 8–76%、折射强度 24–0，并联动饱和度和边缘高光。
- Chromium 启用 SVG 折射。Safari、Firefox 使用透明度与 CSS 磨砂后备方案；不支持 backdrop-filter 的浏览器显示不透明背景。
- 系统“减少透明效果”禁用透明与折射，保留用户选择；强制颜色模式保留系统面板色。
- 位移图最大边 480 像素，尺寸变化时用 ResizeObserver 合并到动画帧重建；滑杆变化不重建位移图。监听器在卸载时清理。
- 侧栏材质留在非滚动外层，导航单独滚动；桌面裁切装饰，避免焦点滚动移动窗口。

## 验证

- `pnpm test` 包含构建：49 个测试文件、497 项测试通过。
- 新增 9 项偏好与参数测试、4 项 UI 集成测试：范围、非法存储、持久化、保存失败、实时更新、切页与重挂载、模型设置接口失败时外观仍可用。
- Chromium 桌面检查：鼠标拖动从 100 到 35、Home/End 端点、刷新恢复 100、透明端实际 SVG 边缘折射、磨砂端背景柔化；控制台无警告和错误。
- 340px 高窗口滚动侧栏到 scrollTop=226，玻璃与侧栏仍同高 290px、顶部均为 65px；材质不再随导航滚走。
- 390px 和 320px 窄屏主内容无横向溢出；收起与恢复保留质感。
- 截图使用隔离示例数据，保存在 output/playwright/glass-controls/：clear-desktop.png、frosted-desktop.png、mobile-settings.png。

Safari/Firefox 以及系统减少透明、强制颜色模式的后备代码已检查，但未在这些浏览器或系统模式中实际运行。本功能是网页材质控制，没有承诺复刻某一版本 Apple 系统。
