# 蓝白配色修订

用户明确选择：干净的黑白灰基底，以 #1769FF 和深蓝分层；放弃棕褐、橄榄、纸黄的视觉方向。本文件覆盖此前界面优化记录中的旧配色决策。

参考 https://github.com/rdev/liquid-glass-react 的轻透明边缘与高光。此轮先通过 CSS 窗口实现玻璃层次；后续已增加可调玻璃材质和自有 SVG 边缘折射，见 [玻璃质感设置](./2026-09-17-glass-controls.md)。配色决策仍保持不变。

## 颜色角色

- 主按钮、进度：#1769FF；悬停：#1056DC。
- 选中项文字：#124BBF；选中项背景：#EDF3FF。
- 深色书封：#002FA7，白字；浅色书封：#EDF3FF / #E1EBFF，#002FA7 文字。
- 正文：#171C26；辅助文字：#596273；面板白色，页面中性浅灰。
- 普通模型配置提示采用中性灰。证据、完成进度采用蓝色，并继续保留文字或图标状态标识。错误和删除保留红色语义。
- 所有新颜色由 src/standalone/tokens.css 定义角色；练习模块 fallback 同步为蓝白体系。
