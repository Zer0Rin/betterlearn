## 真实服务验收

使用独立 MySQL 测试容器、新 Python 环境及临时配置/数据目录，不写原数据库。实际调用已有配置的模型与向量服务：

1. 由 Host 启动迁入的服务，获取本机身份并读取个人资料。
2. 上传包含独有验收事实的 TXT，完成解析、向量化，状态为 ready。
3. 正文接口保留验收标记，BetterLearn 知识源适配器读取成功并生成内容摘要。
4. 基于该文档生成 3 道题，提交作答，生成真实复盘并持久化，历史可以重新读取。
5. 另行完成主题输入、联网检索及 3 道题生成。
6. 解压打包产物到独立目录，成功启动包内服务并读取测试历史。

浏览器验收使用迁入的实际浮窗组件和真实 Host 练习接口，外层为最小 DSH 会话替身：知识库、练习历史和真实复盘可打开；导航未改变宿主 URL，未发现控制台错误。截图保存在本地 `output/playwright/`，不加入源码仓库。该验收不能等同于完整 DSH 插件安装验收。
