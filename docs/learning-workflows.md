# 学习功能使用指南

独立 Web 与 Electron 使用同一套学习页面。以下入口位于左侧导航；已有数据可以直接浏览，出题和 AI 报告需要在“设置”配置模型。

## 从资料准备知识点

1. 在“知识提取”导入资料，确认预览后发起提取。
2. 审核候选与原文证据，接受的知识点可以整理为学习书。
3. 在“学习空间”打开学习书并开始课程。

“知识点出题”、题库来源绑定和学习目标只列出已经开始的活动课程。没有可选课程时，先完成上述步骤，再点“重新读取课程”。

## 练习与成绩

在“开始练习”输入主题或选择知识库资料，指定数量和难度后生成。逐题选择答案并“确认答案”，成功后草稿保存在本机服务；完成题目后“交卷并查看成绩”。

成绩由服务端判分并保存，不等待 AI 报告。可以在成绩页另行点击“生成 AI 报告”；生成失败不影响已保存的成绩。练习历史支持查看同一题卷的不同作答轮次。同一题卷仅首次交卷获得经验值，模拟考试不发经验值。

遇到请求结果未确认，按页面提示重试原请求。存在版本冲突时先核对服务端记录，再决定是否舍弃本地待保存答案。不要把“未交卷”当作零分。

## 题库、来源与知识点出题

“题库”可按当前错题、曾经答错、收藏、分类筛选，也能搜索题干或解析。查看题目可管理收藏、分类、来源，读取作答历史并打开对应成绩。删除分类仅解除分类关系，保留题目与历史。

在题目详情选择课程和知识点后“保存来源绑定”。绑定只影响之后交卷的来源记录，不会重算旧成绩；解除来源也不会删除旧记录。来源表示用户选定的知识点，不表示题目覆盖已经审核。

“知识点出题”可以直接选择课程与知识点，设置要求、3～10 道题、难度和可选配图。点击生成后调用已配置的模型，题目成功保存时自动带上该知识点版本的来源。完成后点击“打开这份练习”。

该入口保存原请求和任务号，刷新后回到“知识点出题”可继续查询。同请求重试不会创建第二个任务；失败任务不会自动再次调用模型，需要显式准备新一组题目。生成的题目仍需检查是否与知识点相符。

## 学习目标与统计

“学习目标”选择课程知识点，设置证据分数、至少完成的不同题目数和截止时间。目标绑定创建时的知识点版本，条件保存后固定；归档或恢复不会延长截止时间。

同版本已有的有效记录可以计入目标；题目重复作答不增加不同题目数。目标分数使用最近最多五道不同题目的首次答案，并应用少样本上限；纠错会更新最近正确率，但不替换首次证据。分数和数量都满足才显示达标。截止后的作答不改变该目标的截止结果。

“学习统计”展示总体数据，以及每个知识点版本的首次、最近和总体正确率、不同题目数与重复作答数。可以查看版本作答记录并打开对应成绩。绑定前的旧记录不会自动补入统计，没有证据的知识点不会显示为零分。证据分数和正确率不等同于课程掌握度。

## 到期复习

“到期复习”汇总 Core 中活动课程的到期与补救任务。按页面完成检查或补救，成功提交后由 Core 保存课程状态并安排下一次时间。题库收藏、练习成绩和考试成绩不会自动覆盖这个队列。

## 模拟考试

1. 在“模拟考试”新建试卷，选择题库中的知识点版本并分配题数。
2. “预览组卷缺口”检查题量；缺题时先补充题库或调整配额。跨来源内容完全相同的题目只占一个名额，不会自动调用模型补题。
3. 创建冻结试卷，逐题核对题意、答案和来源，勾选通过并保存覆盖审核。
4. 全部审核通过后确认开考。此时立即计时；退出、刷新或重启都不会延长截止时间。
5. 作答后点击“保存考试草稿”，确认已保存的题数。页面选择会保留本地草稿，但到期结算只使用此前已保存到服务端的答案。
6. 到期前可主动交卷；到期后点击“结算到期成绩”。未答题计错。最终成绩和来源统计由服务端保存，AI 报告需另行点击生成。

倒计时依赖本机显示，实际截止与会话状态以服务端为准。页面遇到本地草稿与服务端版本冲突时会提示核对，不会静默覆盖。模拟考试用于本机自测，不是监考系统。

## 保存与维护

已交成绩、来源、课程和目标保存在后端数据库；浏览器存储用于界面偏好和待确认请求。桌面与外部浏览器的本地草稿不互通，共用同一 home 的已持久化数据则可读取。Web 与桌面不能同时占用同一 home。

更新或迁移前关闭应用，按 [独立版说明](standalone-web.md) 备份完整 home。安装与运行条件见 [桌面版说明](desktop.md)，接口细节见 [题库集成说明](quiz-integration.md)。
