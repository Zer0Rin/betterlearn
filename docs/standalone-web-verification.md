## 完整服务链路

1. 独立服务空目录启动，设置文本与向量连接；浏览器接口不返回 Key。
2. 文本导入、候选生成、逐字证据定位、接受审核、知识点读取、学习书保存、课程创建与实际作答。
3. TXT 上传、实际解析/向量化、ready 状态、知识库正文预览。
4. 文档向量检索工具执行、RAG 出题、三道题作答、复盘持久化、历史读取。
5. 重复复盘请求直接读取原报告，未重复调用假模型；SQLite 测试验证经验值只增加一次。
6. 关闭服务后成套备份、恢复到新 home，再次启动：书库、课程作答、题目报告均保留；本地图片字节一致。
7. 恢复后的 Chroma 仍能执行检索并完成新的文档出题。
8. 旧版本删除请求返回冲突且课程仍在；匹配版本的学习书删除清理关联课程。

## 审查与恢复保护

审查发现并修复：题目保存失败仍显示成功、文档删除失败被吞掉、设置更新遗漏文档处理状态、HTTP 写入未结束便释放应用锁、多个标签页覆盖书库、旧页面删除课程、供应商异常进入 API/任务状态/日志。

- 关闭程序停止接收请求，等待已接收写入完成，再关闭子服务和释放目录锁；延迟写入回归验证期间无法取得第二个锁。
- SQLite 报告、答案与 XP 事务原子提交，重复调用不重复累计。
- 学习书保存和删除均核对版本；删除日志随备份保存并在启动时恢复。
- 练习/文档中断状态明确标记失败，不自动重复收费生成。
- 供应商与存储异常使用固定安全消息，假密钥哨兵验证 API、后台状态和日志不包含异常秘密。
