# BetterLearn 独立 Web 使用说明

## 运行形态

本机单人应用，默认只监听 127.0.0.1。不提供注册登录、多用户或公网部署。Node 应用服务启动并管理两个隔离 Python 子进程；退出后释放数据目录锁。不得同时让两个应用实例使用同一 home。

Web 页面不需要 DSH 当前会话。知识库、提取审核、学习书、课程进度、练习和历史均通过独立入口使用。Electron 尚未实现。

## 安装与启动

源码安装与命令见仓库 README。解压独立包后，可在任意目录执行：

```bash
node /absolute/path/to/standalone/betterlearn.mjs init --home /absolute/path/to/home --python /absolute/path/to/python3.12
node /absolute/path/to/standalone/betterlearn.mjs start --home /absolute/path/to/home --port 3210
```

需要 Node.js 24+ 与 Python 3.12，当前支持 macOS/Linux。init 安装依赖可能需要联网；构建包没有 Node 运行依赖，Python 环境仍需初始化。init 可重新准备环境，但不会自动备份；对有数据的目录升级前先停止应用并备份。不得将旧 DSH home 直接作为独立版 home。

开发验收可以显式传 `start --python /absolute/core/python --quiz-python /absolute/quiz/python` 使用已有隔离环境，此方式不替代面向普通使用者的 init。

## 工作台窗口

页面默认打开玻璃风格的独立工作台。右上角可收起或最大化；收起后点击页面右侧 BetterLearn 入口恢复。收起不会卸载当前界面，正在编辑的内容、当前选项与提取任务保留。

拖动窗口左边、底边或左下角调整大小。Tab 可聚焦拉伸手柄，方向键每次调整 20px，按住 Shift 调整 50px；左侧手柄按左箭头扩大宽度、右箭头缩小。手动尺寸在此浏览器内记忆，最大化后还原会恢复原尺寸。窄屏自动适配视口，导航随窗口宽度收紧。学习区的课程路径与证据栏仍可分别收起。

玻璃材质集中在窗口与导航，正文保持清晰底色。系统减少动态效果设置会关闭动画；不支持背景模糊的浏览器使用实色底。窗口外壳独立于业务组件，未来可以嵌入其他宿主；本版尚未接入 agent 或原生 SwiftUI。

## 模型设置

文本连接填写 API 根地址（例如服务文档提供的 `/v1` 地址）、模型名称和 API Key。提取需要服务支持 Chat Completions 的指定 function tool calling；仅支持纯文本聊天的接口不能完成结构化提取。出题和复盘共用当前文本模型，现有课程学习逻辑保持原实现。

设置保存仅校验本地格式，不调用模型或证明服务连通。请求认证错误或模型不支持时，会在实际操作中报错。提取任务保存自己的模型配置标识；之后切换文本模型不改变已有任务的重试模型。私有配置会保留旧连接快照以支持此行为。

Embedding 默认配置适配 DashScope 的 OpenAI 兼容向量接口。知识库已有文档时不能直接切换向量模型或地址，避免复用不兼容向量；应先删除文档，再切换并重新上传。仅更换 Key 不改变向量模型。图片生成沿用 DashScope 原生图片接口，联网检索沿用 Tavily，分别按需配置。

正在提取、出题、复盘或处理文档时不要修改配置；服务会拒绝可能中断工作的设置保存，完成后再试。密钥不返回浏览器，留空表示保持已有值，使用清除选项才清除当前用途的 Key。

## 使用路径

1. 在“知识提取”粘贴正文或导入资料，先看正文与调用上限，再开始提取。
2. 在审核页核对逐字引用，接受、编辑或拒绝候选；将选中的知识点整理为学习书。
3. 到“学习空间”打开学习书、作答并保存进度。已开始学习的书修改时生成新版本。
4. 到“知识库”上传文档，等待解析和向量化；可用于提取或基于该文档出题。
5. 在“开始练习”生成题目，完成作答与复盘，在“练习历史”重新查看。

刷新、查看历史不发起新的模型生成。浏览器存储用于恢复当前提取/答题状态，持久书库和课程数据保存在本机服务。若书库在另一标签页更新，当前页保留未保存内容并提示冲突；确认后重新加载最新书库，再重新操作，不提供强制覆盖。

## 存储与故障恢复

home 下主要目录：

| 路径 | 内容 |
| --- | --- |
| core/phase1.db | 提取、审核、知识点、课程及掌握度 |
| quiz-data/quiz.sqlite | 文档元数据、题目、复盘与学习统计 |
| quiz-data/uploads/ | 知识库上传文件 |
| quiz-data/chroma/ | 向量与检索数据 |
| quiz-data/images/ | 本地生成配图 |
| library.json | 学习书目录和版本 |
| settings.json | 私有模型配置与提取连接快照 |
| quiz.env | 从设置派生的子服务配置，不要手工编辑 |
| identity.json | Core 数据目录身份 |
| venv/、quiz-venv/ | 两个 Python 依赖环境 |

应用重启时将未完成的文档处理和出题任务标记为中断失败，用户可以重新发起；不自动重新调用模型，也不承诺断点续跑。Core 保留原恢复规则。学习书删除使用恢复日志，若关闭发生在删除过程中，下次启动继续完成已请求的删除。

## 备份与恢复

先退出应用。backup 使用与应用相同的数据目录锁，运行中的实例会阻止备份。输出是新目录，包含文件校验清单、两个数据库、上传文件、Chroma、本地图片、书库、身份和私有设置；不包含 Python 环境与外部 COS 对象。

恢复只写全新目录，先验证备份文件和校验值，再发布恢复目录。恢复后执行 init 创建环境；应用会生成匹配新路径的 quiz.env。不要手工拼接不同时间点的 SQLite/上传文件/向量目录。现有旧数据迁移另行处理，本次未执行。

## 当前边界

真实供应商的模型质量、额度、接口差异仍需按实际配置验证；本次独立版验收使用假模型，不等同于真实模型效果验收。扫描 PDF 不提供 OCR。课程掌握度与独立练习统计仍各自保存。首次启动无需 MySQL、COS 或 DSH，但知识库向量化和 AI 生成需要对应模型服务。
