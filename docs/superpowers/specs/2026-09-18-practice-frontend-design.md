# 练习与成绩前端接入

日期：2026-09-18。状态：用户已确认，第一阶段前端已实现并验证，所有改动未提交。

## 范围与选择

前端恢复后的第一阶段：练习、服务端草稿、交卷、成绩、多轮历史、独立 AI 报告。复用现有 Web/Electron 共享页面和样式。

推荐按完整业务流程接入现有 attempt API。仅替换报告按钮无法解决刷新恢复、虚假 XP 和历史成绩不可见；同时开发题库、复习、目标和考试则扩大验证范围。这些后续页面按用户提出的顺序另行推进。

## 已核对的现状

- QuizWorkspace.finish 调用旧 report/generate，保存成绩仍与前端报告流程绑定。
- QuizReport 按本地 records 计算正确率与 XP，不能正确表达同卷重练的 0 XP。
- HistoricalReport 没有 report 时不显示成绩；HistoryPage/Home 把未交卷的占位 0 显示为正确率。
- session.ts 只有浏览器练习缓存，尚无 attempt_id、revision 或稳定创建请求键。
- 后端已提供创建/列举/读取 attempt、全量部分答案保存、交卷和独立报告接口。保存使用修订号，交卷须答完全部题目，报告必须显式发起。

## 页面行为

### 开始与继续练习

生成完成后创建服务端作答轮次；创建前保存稳定 request_id，响应丢失时复用原编号。开始答题前取得服务端 attempt 快照。继续练习优先读取已知 attempt_id；历史详情列出各轮草稿和成绩，用户可选择恢复或明确开启新一轮。

逐题确认后保存完整的已答快照，显示“保存中／已保存／保存失败”。保存串行，返回的 revision 才可用于后续写入；失败保留本地答案并提供恢复操作。选项尚未确认时不宣称已保存。继续沿用练习的逐题解析，明确它只是练习反馈，正式成绩以交卷结果为准。

刷新后核对服务端记录；本地未同步答案不得静默覆盖远端。409 时暂停写入并提供重新读取入口，本地副本保留到用户明确放弃。请求结果未知时先只读查询；若远端与待保存快照不一致，明确展示冲突而不自动提高 revision 重发。

### 交卷与成绩

最后一题后的按钮改为“交卷并查看成绩”。等待草稿写入完成，冻结完整提交载荷后调用 submit；提交期间禁用重复操作。网络失败先查询该轮状态，已交卷直接显示结果；需要重试时保持同一轮次与原提交载荷。

成绩页读取服务端 accuracy、correct_count、total_questions、xp_gain、submitted_at 和正式答案。未交卷不渲染正式分数；0 分和 0 XP 均正常展示。交卷成功即可回看成绩和解析，无需模型配置或报告成功。

### AI 报告

成绩页单独提供“生成 AI 报告”，说明使用已配置模型。初次查看、刷新、交卷和进入历史都不自动调用生成接口。按 not_requested/running/completed/failed 显示入口、状态、报告或重试按钮。

请求中断先 GET 查询状态；running 仅有界轮询读取，超时提供继续查询，failed 才提供显式重试。报告失败不隐藏成绩，不重新交卷或创建轮次。报告里的总结不替代服务端成绩，也不把模型判断表述为正式掌握度。

### 历史与兼容

首页和历史列表用 status 区分“未交卷”和真实 0 分；成绩使用交卷时间。每卷仍一行，详情使用 attempts 列表选择轮次，草稿继续、成绩回看和同卷重练均有明确入口。已交卷但无报告的轮次仍可正常查看。

旧缓存无 attempt_id 时先查询该卷轮次，不自动导入或覆盖服务端已有答案；提供明确的旧本地进度恢复入口，以新稳定 request_id 创建轮次并保存合法答案，遇到旧数据不满足新契约则保留缓存并说明原因。仅有旧报告、没有可用 attempt 的异常历史以只读兼容视图展示，不补造成绩或 XP。

## 实现边界

在 types.ts/contracts.ts/api.ts 增加 attempt 类型和请求；将轮次读取、保存、提交及报告状态管理从 QuizWorkspace 抽到专用模块，页面复用同一逻辑。session 缓存保存恢复标识和未同步载荷，不承担成绩事实来源。保持现有生成、知识库、导航和桌面壳功能。

本阶段不修改后端业务规则，不启动用户日常 home，不调用真实收费模型，不提交或清理已有改动。

## 验收

- 草稿保存后卸载/重新挂载可恢复；保存失败与修订冲突不丢答案、不静默覆盖。
- 创建响应丢失不重复建轮次；交卷重复点击和响应丢失不重复提交新的内容。
- 交卷成功、报告失败仍展示服务端成绩；查看与刷新不调用报告生成。
- 报告运行中只查询，显式失败重试成功后成绩、时间、XP 不变。
- 同卷多轮历史独立，重练 XP=0 展示准确；未交卷与真实 0 分可区分。
- 验证旧缓存/旧报告、退出重入、轮次切换期间迟到响应和 React 卸载后的状态隔离。
- 运行相关前端和 API 单测、Web 全套、构建及 diff 检查；使用 fake provider/临时数据验证实际 HTTP 流程。
