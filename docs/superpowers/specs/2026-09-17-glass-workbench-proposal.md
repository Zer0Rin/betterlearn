# BetterLearn Web 玻璃工作台优化提案

状态：用户已确认，实施与验收完成。

## 目标与现状

基于独立 Web 的 aabbfd9，优化知识库、提取审核、学习书、出题、答题、复盘和历史的视觉一致性，保留插件式可收起、可伸缩的窗口体验，为后续 agent 宿主和 Electron 接入保留边界。

当前 src/standalone/App.tsx 使用固定侧栏全页布局；旧 src/client/floating-workbench.tsx 拥有收起入口、左边/底边/左下角拉伸、按流程记忆尺寸、学习模式尺寸恢复。旧入口依赖 DSH 会话，不能直接成为独立 Web 的依赖。workbench-size.ts 是可复用的纯尺寸逻辑；learning-layout.ts 已管理学习区左右栏开关。

## 参考与方案比较

- 推荐：React 业务组件保留，增加独立宿主无关的可伸缩外壳，以 CSS 实现玻璃层次。浏览器兼容性、正文清晰度和未来宿主接入较易控制。
- 重度折射：采用 liquid-glass-studio 的 GPU 渲染思路，视觉更接近真实折射，但需要额外处理画布、DOM 内容、资源消耗和降级。本轮不作为基础依赖。
- 控件体系迁移：引入 WebSwift 的 Web Components，统一类 SwiftUI 控件，但需要适配当前 React 表单和交互，改动范围更大。本轮借鉴其控件层次与布局，不迁移整套组件体系。

来源：
- https://github.com/iyinchao/liquid-glass-studio （WebGL2 / WebGPU 玻璃效果项目）
- https://github.com/Mengobs/WebSwift （TypeScript + Web Components 控件实现）
- https://github.com/electron/electron/blob/main/docs/tutorial/native-code-and-electron-swift-macos.md （Electron 原生 SwiftUI 桥接）

## 视觉设计

浅色为本轮默认。背景使用雾蓝 #EAF0F6，内容面板 #FBFCFE，正文 #202B3B，次级文字 #637085，交互蓝 #3267D6，成功色 #2F8169。错误与待审核状态保留可辨识的语义色与文字。

使用系统 UI 字体栈和 PingFang SC；标题通过字号、字重与留白区分，辅助数据采用系统等宽字体。无需下载外部字体或图片。

玻璃效果集中在标题栏、导航、浮动入口：适量背景模糊、细亮边、浅阴影。正文、证据、输入框、答题区使用高不透明度背景。卡片、按钮、输入框统一圆角和间距，减少书库、提取区、练习区之间的视觉跳变。

## 窗口与扩展边界

独立 Web 默认展开居中的学习工作台，提供收起、恢复、最大化/还原和三向拉伸。收起后显示边缘入口，恢复时保留当前工作内容。最大化是应用布局状态，不调用浏览器全屏接口。还原恢复此前手动尺寸。

窗口外壳只处理尺寸、可见性、工具栏与内容插槽；独立 App 继续管理 API、学习书持久化、模型配置和业务导航。避免为恢复窗口行为重新引入 DSH。复用纯尺寸计算，独立 Web 的窗口设置使用单独版本键，避免污染旧插件设置。

缩放时内容根据容器宽度调整：宽窗口显示图标加文字导航，较窄窗口压缩导航；小屏采用视口内最大可用尺寸，收起和恢复仍可用。学习区左右栏继续独立收起。窗口缩放不能使答题、保存、审核按钮不可达。

收起只改变可见性，不卸载业务树；进行中的提取、编辑和答题保持状态。窗口外壳不承担任务执行器，不在本轮加入 agent 聊天或命令系统；未来宿主通过外壳属性/回调和内容插槽接入。

## 覆盖范围与错误处理

覆盖窗口外壳、导航、书库与书籍卡片、知识提取与审核、学习区、练习与报告、历史和设置的样式统一。维持已有业务接口和保存冲突处理，不调整数据格式、模型调用或后端。

保留现有加载、空态、保存失败、模型未配置和重试入口，统一呈现层次。模糊不受支持时降级为实色面板；减少动态效果设置生效，拖动期间关闭尺寸过渡。拉伸手柄提供可访问名称和键盘调整方式；收起后焦点回到入口，恢复后焦点进入窗口。

## 实施与验收

先实现外壳及状态保留，再统一视觉，最后逐流程浏览器验收。针对新增窗口行为验证尺寸边界、尺寸记忆、最大化还原、收起恢复不丢状态和键盘操作；复用业务回归测试，执行 Web 构建与测试。

浏览器验收覆盖宽窗口、窄窗口、移动视口；核对书库、提取审核、学习、练习、报告、历史及设置，检查溢出、滚动、焦点和对比度。使用隔离验收数据及模拟供应商，不将模拟结果表述为真实模型效果验收。

Electron、SwiftUI 原生桥接、真实供应商验收、原数据迁移不在本轮范围。
