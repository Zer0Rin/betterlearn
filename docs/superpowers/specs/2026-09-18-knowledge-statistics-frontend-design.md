# 知识点版本统计前端

用户继续授权收完整前端。现有学习统计只显示总体数据，而知识点统计后端已具备只读 API；本次沿用该契约和页面视觉。

在学习统计总体指标后加入知识点版本列表，按服务端顺序分页。每项显示知识点、历史版本、首次/最近/总体正确率、不同题目和重复作答数量、交卷轮数。说明统计基于交卷时冻结的来源，不等于课程掌握度；无证据显示为空，真实零分显示 0%。

点击版本读取该知识点 ID + 版本的分页作答记录；以服务端入库顺序展示，并可跳到该 quiz/attempt 的成绩。时间统一复用 UTC 转本地显示。不用前端重算统计、不改课程状态、不调用模型。

加载与错误明确区分，刷新失败不展示旧页为新结果；切换版本/卸载终止请求并忽略迟到响应。分页数据缩小时回退到有效页。个人资料和总体指标保留。
