# 多来源组卷、覆盖审核与模拟考试后端

用户要求“把后端做完”，沿用前端暂停、保留工作树、不提交、不调用真实模型约束。本次范围是上一阶段明确列出的三项缺口。

采用现有题库组卷，而非新增一次大模型调用或引入 DeepTutor 整套 agent。复用 DeepTutor 改编判分、版本题库、精确内容去重和既有成绩/报告流水线。题量不足显式返回缺口；可以通过已有单来源生成接口补充题库。组卷不暗中生成题目。

## 组卷与审核

POST /exam-papers/preview 只读预览；POST /exam-papers 创建冻结草稿（UUID幂等）。输入标题、时长60..14400秒、1..20项知识点ID+内容版本+题数（总计1..100）。按分配顺序、题库ID稳定选择本用户已绑定该版本的题目，全卷精确内容去重、校验标准答案。不足不创建部分卷，预览返回各来源缺口。不得把标签或模型自由文本当可信来源。

草稿保存题目、题库来源ID与关联版本、完整Core来源快照；之后题库改绑或Core删除不影响草稿。GET详情提供可审核题目/答案与逐题来源。PUT /{paper_id}/review 使用expected_revision、完整逐题approved/rejected和备注（可空），保存用户显式审核。全部批准才可开考；分配数量检查与用户审核是两个独立条件，不宣称语义覆盖已被机器证明。冻结试卷不可编辑，修改内容需新请求建卷；审核在首次开考后锁定。

## 考试

POST /exam-papers/{paper_id}/sessions（UUID+expected_revision）冻结审核版本并创建持久会话，幂等重放不重置计时。GET /exam-sessions/{session_id} 返回题干/选项/题型/配图和已存草稿，不返回标准答案、解析、正确性或来源正文。考试题目使用卷内新ID。单用户题库仍可查阅，因此这是自测而非防作弊系统。

PUT /{session_id}/answers 为全量草稿替换、CAS版本，支持漏题/空选项；同操作丢响应重放不重复增版本。服务端UTC创建deadline，截止时刻起禁止保存。GET保持只读，过期状态为expired；下一次POST submit按截止前已保存草稿结算，忽略迟到答案。交卷前可POST submit提交当前完整/部分答案；未答算错，多选严格集合相等，不设部分分。提交请求幂等，冲突不覆盖成绩；到期结算支持重复读取同结果。时钟是本机服务端UTC，重启不延长考试。

## 成绩与报告

交卷在单个SQLite事务内保存最终考试结果，并创建已交卷的普通quiz/attempt及冻结来源投影；此前不会创建可经旧API读取答案的quiz/attempt。复用题库历史和知识证据统计（精确内容去重保持原语义）。考试成绩包含总分百分比、逐题、各来源得分和交卷原因。组卷来自已有题库，考试XP固定0，不刷经验、不自动改Core掌握度。已交卷attempt可通过现有独立报告入口请求AI报告；报告失败不影响成绩。

列表分页、用户隔离、严格参数、同源Host代理遵循现有规则。新增Quiz schema7，v1..6迁移前备份，事务失败回滚。备份恢复覆盖整库，Core schema2不变。MCP本轮维持17工具，完整新能力通过产品HTTP API提供；前端及考试MCP适配不属于这三项后端缺口。

## 验收

真实临时SQLite/API：预览无写、重复内容/缺口、多版本/跨用户隔离、并发幂等、审核CAS和锁、冻结来源、交卷前白名单、草稿冲突/丢响应、精确截止/迟到、漏题、多选、重启、原子回滚、可信题库历史/分来源统计、报告失败重试不改成绩/XP。迁移测试覆盖旧版本备份和失败回滚；Host路由白名单和真实服务链路；Web/Quiz/Core及插件回归。禁止触碰日常home与真实模型。
