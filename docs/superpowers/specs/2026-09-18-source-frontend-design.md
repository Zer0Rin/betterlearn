# 来源绑定与按知识点出题前端

用户在四阶段前端完成后继续授权，并明确选择本范围。沿用现有页面视觉和后端契约，不新增数据库或模型协议。

- 题库详情独立读取当前来源和 source_revision。选择活动课程与单元，仅提交 courseId/unitId；保存/解除使用原 revision。说明绑定不重算旧成绩、不代表覆盖审核通过。
- 独立“知识点出题”入口选择活动课程、知识点、题数 3–10、难度、出题要求和可选配图。只有显式生成才调用模型，说明可能产生费用。
- 写请求先存本机恢复记录；刷新、丢响应重试沿用同一参数/请求号，不自动换号。绑定确定拒绝后可清除并重读，未知结果只允许原请求重试。
- 生成返回任务号后持久化，轮询已有任务接口，十五分钟停止自动查询并提供继续查询。终态允许显式准备新请求，失败不自动重试模型。成功进入现有练习详情；自动来源只表示出题意图，考试仍需审核。
- 存储失败不发送；其他窗口更改恢复记录时不覆盖。服务端是来源、版本、任务和成绩事实的唯一来源。

验证覆盖原请求恢复、CAS 冲突、存储失败、跨窗口保护、明确点击生成、失败无自动重试、真实 Host 自动关联和任务重放。
