# 题库与复习前端

2026-09-18。用户以“继续”授权沿既定顺序推进第二阶段，沿用现有界面与共享 Web/Electron 前端。

## 页面与边界

- 导航增加“题库”和“到期复习”。题库按全部、当前错题、曾经答错、收藏、未分类筛选；可分页、字面搜索、按创建时间排序和分类过滤。未答题显示未作答，当前错题采用服务端最近一次结果。
- 题目详情展示冻结题干/选项、可展开答案解析、收藏、分类关联与独立分页的交卷历史。历史可打开对应原卷轮次；“练习这份题卷”进入已有练习入口，不虚构单题组卷 API 或自动调用模型。
- 分类管理采用已有 DeepTutor 交互的可复用部分，适配本项目类型和样式：新建、改名、删除及单题关联/移除。删除前在页面展示分类名称与影响，删除仅解除分类关联，不删题和成绩。
- 收藏与分类更新按显式目标值发送，写入期间锁定重复操作，写失败保留输入并要求重新读取；创建分类没有幂等键，网络异常不自动重发。列表/详情读请求须忽略过期返回。
- 到期复习直接读取 Core 跨课程队列，显示课程、知识点、到期时间和补救状态；初始不展示标准答案。提交后展示服务端判定与下次复习时间，答错可刷新队列进入补救，补救后仍以服务端最新状态为准。
- 复习提交在本地先持久化完整请求（unitId、assessmentId、optionId、expectedAttemptId、idempotencyKey）。结果不确定时保留选择与原请求，只允许显式同键重试，不自动更换键。409 提示状态已变化，明确放弃旧待提交记录后重新读队列；不覆盖其他窗口记录。
- 题库记录与 Core 复习是两个事实来源；不将收藏或题库成绩直接换算为 Core 掌握度。复习不依赖 quiz 登录或模型配置。

## 验证与约束
