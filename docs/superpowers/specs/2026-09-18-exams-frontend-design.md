# 模拟考试前端

用户继续授权第四阶段。沿用现有共享界面与接口，保留已有工作树，不提交。

- 分页试卷/考试列表，支持继续答题和回看成绩。
- 从题库当前冻结来源选择最多二十个知识点版本，设置各自题数与时长；先只读预览缺口，条件变化使预览失效。满足配额后才创建试卷，不自动出题。
- 逐题显示题干、选项、标准答案/解析及来源正文，让用户显式勾选审核并写备注。保存完整审核；全部通过并使用最新 revision 才能明确开考，开考立即计时。
- 所有写操作发送前持久保存完整输入；创建与开考固定 UUID，审核/草稿/交卷固定 revision。未知结果只能原请求重试，已知拒绝可明确放弃并重读，不提升 revision 或覆盖其他窗口记录。
- 考试页只使用会话题目，不加载审核答案。选项支持单选/判断/多选，编辑草稿本地保存，显式保存到服务端；未保存状态清楚显示。再次打开按 revision 检查本地草稿，冲突须明确丢弃本地记录。未交卷读请求不清除未知写请求。
- 倒计时为本机估算，服务端截止裁决；定期只读更新状态。到期停止编辑并显式结算，只用已保存答案。结果展示总分/未答/各来源/逐题答案，独立报告打开已有指定 attempt 的报告流程。
- 单用户自测可查看原题库，不承诺防作弊。考试不改 Core 掌握度，不发 XP。

验证覆盖 API、持久请求、预览失效、逐题审核门槛、选择/保存/截止/恢复与独立报告导航；真实临时 Host + fake provider、Web 全量/构建和浏览器。无真实收费 API，无后端规则变更。
